Downloads

Everything you need in one place: the paper, the full package to re-run the results (code, trained models and guides), and the original sources.

The paper

⬇ paper.pdf   LaTeX source ↗

"iDEFT: Intelligent Backup-Node Selection for Fault-Tolerant Network Function State Replication", IEEE conference format, 10 pages. The LaTeX source includes the bibliography and the scripts that draw every figure.

The package to re-run everything

The backup-node-selection/ folder has everything in it: the experiment code, DEFT's own 2PC classes unchanged, five trained RL models, the saved results, the paper, and both guides (EXPERIMENTS.md, IMPLEMENTATION.md).

⬇ Latest release   Repo snapshot (.zip)   Browse on GitHub ↗

The release holds only the backup-node-selection package. The repo snapshot also includes the older Mininet folders, which you do not need to re-run any of the results here. 

git clone https://github.com/bijoy111/ideft.git
cd iDEFT/backup-node-selection
