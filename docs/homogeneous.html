What this means: at this small size, with every host about equally good, any method that avoids piling primaries onto one backup does about as well as any other. The smarter methods gain nothing over plain round-robin here. The real gap is between the methods that pile up load (baseline, concentrated) and everything else. What drives the difference at this size is load sharing, not host quality (see the backup-load check on the 16-host page). Knowing which host is good only starts to pay off once hosts actually differ.
