Reading: the latency term, evaluated against measured RTT, is what provides
degraded-host avoidance. The health term is dispensable. This inverts the
conclusion drawn under the binary degradation model, where every configuration
avoided degraded hosts and the sweep could not discriminate at all.

Caveat: in this model every degradation kind carries some latency signature,
so measured RTT is close to a sufficient statistic here. A failure mode with
no latency signature (a host that is currently fast but about to fail) would
not be caught by it, and would need the health signal instead.
